# Boletería API - EVA 2 Backend

Proyecto 3: Venta de entradas para eventos y conciertos.
Django REST Framework + PostgreSQL + JWT.

## Cómo ejecutar
1. Crear la base de datos en PostgreSQL
2. Completar el archivo .env con los datos de la base de datos y del alumno
3. pip install -r requirements.txt
4. python manage.py migrate
5. python manage.py cargar_demo
6. python manage.py runserver

Swagger: http://127.0.0.1:8000/api/docs/
